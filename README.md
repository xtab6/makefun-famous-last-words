A phone's last words at 1% battery — one line, in the phone's own voice, with a twist at the end: it was never dying, it just wanted to be put down.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
